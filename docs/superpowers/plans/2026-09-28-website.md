# rumd Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a professional static website for rumd with the logo, real
app screenshots, advantages, features, shortcuts, and build instructions.

**Architecture:** Two deliverables. First, a throwaway test inside
`src/app.rs`'s existing `#[cfg(test)] mod tests` renders the real app
headlessly via `egui_kittest::Harness` at 1280×800 and writes four PNGs into
`website/assets/`; the test is then removed. Second, a zero-JavaScript
single-page site (`index.html` + `style.css`) that consumes those assets.

**Tech Stack:** Rust test harness already in the codebase (egui_kittest),
plain HTML5 + CSS3. No build step, no frameworks, no external requests.

**Spec:** `docs/superpowers/specs/2026-09-28-website-design.md`

## Global Constraints

- Zero JavaScript on the site: no `<script>` tags anywhere.
- No external network requests: no web fonts, CDNs, or remote images. System
  font stacks only.
- All asset references are relative paths (site must work from `file://`).
- Placeholder GitHub URL is exactly `https://github.com/TODO-rumd/rumd`
  everywhere it appears; its first occurrence carries the comment
  `<!-- TODO: before publishing, find & replace this placeholder URL with the real repository URL -->`.
- Palette (verbatim): page bg `#0d1420`, raised surfaces `#151d2e`, text
  `#e8ecf4`, muted text `#94a3b8`, accent `#3b82f6`, borders `#223049`.
- Every product claim on the site must be traceable to `README.md`. Nothing
  invented.
- The throwaway screenshot test is removed from `src/app.rs` after capture;
  `cargo test` must pass afterwards with no trace of it.
- The `rumd` crate is binary-only (no `[lib]` in Cargo.toml), so the capture
  test MUST live in `src/app.rs`'s test module — integration tests in
  `tests/` cannot import `app::App`.

## Review Focus

- **Broken asset paths from `file://`** — a reader opening
  `website/index.html` directly expects every image to resolve; a single
  leading-slash or wrong-case path shows a broken icon. Pinned by Task 2
  step "Verify every asset reference resolves".
- **Placeholder URL leaking into a real deployment** — a visitor clicking
  GitHub must not hit a 404 after publishing; the placeholder must be
  findable by one search. Pinned by Task 2 step "Verify external links are
  placeholders only".
- **Stale or blank screenshots** — a capture taken before the UI settled
  would show an empty pane and misrepresent the app on the front page.
  Two `harness.run()` frames before each snapshot (the existing snapshot
  tests' pattern) guards this; pinned by Task 1 step "Verify captures".
- **Feature claims drifting from README** — invented claims ("GPU
  accelerated", "MIT licensed") would misrepresent the project. Pinned by
  Task 2 step "Cross-check copy against README".

````rust
    #[test]
    fn website_screenshots() {
        const SAMPLE_DOC: &str = r#"# Welcome to rumd

A cross-platform **markdown viewer** in *pure Rust*. This document shows
what rumd renders — and it stays in sync as you type.

## Tasks

- [x] Rendered markdown
- [x] Live reload from disk
- [ ] Take over the world

## Table

| Feature | Status |
|---|---|
| GFM tables | supported |
| Task lists | supported |
| Syntax highlighting | supported |

## Code

```rust
fn main() {
    println!("Hello, rumd!");
}
```

> Markdown should be pleasant to read — and to watch being written.

Links work too: [the rumd website](https://example.com) — and everything
stays local on your machine.
"#;

        fn shoot(mut harness: Harness, out: &std::path::PathBuf, name: &str) {
            harness.run();
            harness.run();
            let mut opts = egui_kittest::SnapshotOptions::default();
            opts.output_path = out.clone();
            harness.snapshot_options(name, &opts);
        }

        fn harness_for(app: &Rc<RefCell<App>>) -> Harness {
            let app_for_ui = app.clone();
            Harness::builder()
                .with_size(egui::vec2(1280.0, 800.0))
                .build_ui(move |ui| {
                    app_for_ui.borrow_mut().show(ui);
                })
        }

        let doc = stable_path("website");
        let _cwd = CWD_LOCK.lock().unwrap();
        std::fs::write(&doc, SAMPLE_DOC).unwrap();
        let out = PathBuf::from(env!("CARGO_MANIFEST_DIR")).join("website/assets");

        // dark rendered
        let app = Rc::new(RefCell::new(App::new(None)));
        app.borrow_mut().open_path(&doc);
        shoot(harness_for(&app), &out, "dark_rendered");

        // dark split
        let app = Rc::new(RefCell::new(App::new(None)));
        app.borrow_mut().open_path(&doc);
        app.borrow_mut().mode = ViewMode::Split;
        shoot(harness_for(&app), &out, "dark_split");

        // light rendered
        let app = Rc::new(RefCell::new(App::new(None)));
        app.borrow_mut().theme_pref = egui::ThemePreference::Light;
        app.borrow_mut().open_path(&doc);
        shoot(harness_for(&app), &out, "light_rendered");

        // dark search (bar opened with Ctrl+F, query pre-seeded)
        let app = Rc::new(RefCell::new(App::new(None)));
        app.borrow_mut().open_path(&doc);
        app.borrow_mut().search.query = "markdown".into();
        let mut harness = harness_for(&app);
        harness.key_press_modifiers(egui::Modifiers::CTRL, egui::Key::F);
        shoot(harness, &out, "dark_search");

        std::fs::remove_file(&doc).unwrap();
    }
````

Note: `Harness`, `Rc`, `RefCell`, `PathBuf`, `egui`, `ViewMode` and the
helpers `stable_path` / `CWD_LOCK` are already imported and in scope in this
module (the existing snapshot tests use all of them).
